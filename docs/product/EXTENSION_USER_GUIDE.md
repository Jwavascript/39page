# 39page 확장 사용 안내 (M10)

YouTube 에서 듣던 곡과 "지금 이 순간" 을 39page 로 담는 Chrome 확장.

## 설치

**스토어 게시 전** — 압축해제된 확장으로 설치한다 (데스크톱 Chrome).

1. `extension/` 에서 `npm run package` → `release/39page-extension-<버전>.zip` 을 압축 해제한다.
2. Chrome 에서 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기.
3. **압축해제된 확장 프로그램을 로드합니다** → 압축 해제한 폴더 선택.
4. 툴바의 퍼즐 아이콘에서 39page 를 고정하면 누르기 쉽다.

필요한 것: Chrome 102 이상. **Android Chrome 은 확장을 지원하지 않는다** — 휴대폰에서는 39page
웹앱만 쓴다.

## 플레이리스트에 담기

1. YouTube 에서 영상을 연다.
2. 39page 아이콘 → **플레이리스트에 추가** (또는 단축키 **Alt+Shift+Y**).
3. 새 탭에 39page 확인 화면이 열린다. 플레이리스트를 고르고 **플레이리스트에 추가** 를 누르면 저장된다.
   누르기 전에는 아무것도 저장하지 않는다.
4. 이미 그 목록에 있는 곡이면 "이미 있습니다" 라고 알려 준다 — 그래도 한 번 더 넣을 수 있다.

## 지금 이 순간 (Moment) 저장

1. YouTube 에서 영상을 **재생**하고, 남기고 싶은 지점에서 (멈추거나 재생 중에)
2. 39page 아이콘 → **현재 Moment 저장** (또는 **Alt+Shift+M**).
   누른 순간의 영상과 재생 시점(초 단위, 내림)이 고정된다.
3. 새 탭의 확인 화면에서 메모(선택, 500자까지)를 쓰고 **Moment 저장**.
4. 39page 대시보드의 Moments 에서 그 순간부터 다시 들을 수 있다.

메모를 쓰다가 탭을 닫거나 새로 고치려 하면 브라우저가 한 번 묻는다.

## 단축키

| 동작                | 기본        |
| ------------------- | ----------- |
| 플레이리스트에 추가 | Alt+Shift+Y |
| 현재 Moment 저장    | Alt+Shift+M |

팝업에 **지금 지정된** 단축키가 보인다. 다른 프로그램과 겹쳐 지정되지 않았으면 "단축키 지정되지
않음" 으로 보이고, 팝업의 **단축키 바꾸기** 로 바꿀 수 있다 (`chrome://extensions/shortcuts`).
단축키로 담지 못하면 아이콘에 `!` 가 잠깐 붙고, 아이콘에 마우스를 올리면 이유가 보인다.

## 이럴 때는

| 안내                                            | 할 일                                                                    |
| ----------------------------------------------- | ------------------------------------------------------------------------ |
| 재생 위치가 아직 정해지지 않았습니다            | 영상을 재생한 뒤 다시 누른다 (재생 전 · 불러오는 중에는 고정하지 않는다) |
| 광고가 재생 중입니다                            | 광고가 끝난 뒤 다시 누른다                                               |
| 그 사이 영상이 바뀌었습니다                     | 자동으로 다음 영상으로 넘어갔다. 지금 영상을 확인하고 다시 누른다        |
| Shorts 는 아직 Moment 를 저장할 수 없습니다     | Shorts 는 플레이리스트에 담기만 된다                                     |
| 라이브 방송은 아직 Moment 를 저장할 수 없습니다 | 라이브는 플레이리스트에 담기만 된다                                      |
| 다른 탭에서 … 바뀌어 최신을 불러왔습니다        | 다른 39page 탭이 먼저 저장했다. 확인하고 다시 누르면 둘 다 남는다        |
| 다른 39page 탭이 저장하는 중이라…               | 잠시 뒤 다시 누른다                                                      |
| 이 페이지를 읽을 수 없습니다                    | YouTube 영상 페이지에서 아이콘을 다시 누른다                             |

## 개인정보

확장은 누른 탭의 영상 정보만 읽어 39page 확인 화면으로 넘기고, 저장하지도 서버로 보내지도 않는다.
자세한 내용은 [`EXTENSION_PRIVACY.md`](EXTENSION_PRIVACY.md).
