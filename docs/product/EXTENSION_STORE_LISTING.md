# Chrome 웹 스토어 등록 정보 — 초안 (M10-6)

**초안이다.** 제출 전에 사용자가 검토하고 고친다. 스토어 정책은 바뀔 수 있으므로 제출할 때
개발자 대시보드의 안내와 [프로그램 정책](https://developer.chrome.com/docs/webstore/program-policies/policies)을
다시 확인한다. 설명은 실제 동작과 같아야 한다 (정책 "메타데이터 정확성").

## 1. 기본

| 항목 | 값                                                                                                                                                 |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 이름 | 39page                                                                                                                                             |
| 요약 | YouTube 에서 보고 있는 영상과 지금 이 순간을 39page 로 담습니다. 저장은 39page 화면에서 직접 확인하고 합니다. (manifest `description`, 73자 ≤ 132) |
| 분류 | 생산성 (사용자가 확인)                                                                                                                             |
| 언어 | 한국어                                                                                                                                             |
| 버전 | 1.0.0                                                                                                                                              |

## 2. 자세한 설명

> 39page 는 음악 중심의 개인 대시보드입니다. 이 확장은 YouTube 에서 듣던 곡을 39page 로 옮기는
> 일을 짧게 만듭니다.
>
> • 플레이리스트에 추가 — 지금 보고 있는 YouTube 영상을 39page 의 플레이리스트에 담습니다.
> 링크를 복사하지 않아도 됩니다.
> • 현재 Moment 저장 — 지금 재생 중인 시점을 누른 순간 그대로 고정합니다. 39page 화면에서
> 메모를 쓰고 저장하면, 나중에 그 순간부터 다시 들을 수 있습니다.
>
> 확장은 저장하지 않습니다. 버튼을 누르면 39page 의 확인 화면이 새 탭으로 열리고, 그 화면에서
> 직접 고르고 저장합니다. 담은 곡과 Moment 는 이 브라우저의 39page 에만 저장되며 서버로
> 보내지 않습니다.
>
> 단축키: Alt+Shift+Y (플레이리스트에 추가) · Alt+Shift+M (현재 Moment 저장). chrome://extensions/shortcuts 에서 바꿀 수 있습니다.
>
> 지원: youtube.com 의 영상 페이지. Shorts 와 라이브 방송은 플레이리스트에 담을 수 있지만
> Moment 는 아직 저장할 수 없습니다. YouTube Music 은 아직 지원하지 않습니다.

## 3. 단일 목적 (Single purpose)

> YouTube 에서 사용자가 보고 있는 영상(과 그 재생 시점)을 사용자의 39page 대시보드로 보내는 것.
> 두 동작(플레이리스트에 추가 · 현재 Moment 저장) 모두 이 한 목적에 속한다.

## 4. 권한 사유 (Permission justification)

| 권한        | 사유 (스토어 입력란)                                                                                                                                                                                                |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `activeTab` | 사용자가 확장 아이콘이나 단축키를 누른 그 탭의 주소를 읽어, 지금 보고 있는 것이 YouTube 영상인지와 영상 ID 를 확인한다. 상시 접근 권한(호스트 권한)을 요청하지 않는다.                                              |
| `scripting` | 사용자가 누른 그 탭에서만, YouTube 플레이어가 지금 띄운 영상의 ID · 제목 · 재생 시점을 읽는다(읽기 전용). 페이지를 바꾸지 않는다. 주소만으로는 SPA 이동 중의 영상과 제목이 어긋날 수 있어 플레이어에서 함께 읽는다. |
| 원격 코드   | 사용하지 않음 — 모든 코드가 패키지 안에 있다.                                                                                                                                                                       |

`commands`(단축키)는 권한이 아니다. 단축키 실행은 그 탭에 `activeTab` 을 준다.

## 5. 개인정보 관행 (Privacy practices) — 데이터 사용 양식 초안

확장 자체는 데이터를 **저장하지도, 서버로 보내지도** 않는다. 다만 사용자가 누르면 그 탭의 정보를
39page(같은 브라우저의 사용자 자신의 대시보드)로 넘긴다. 양식에는 보수적으로 적는다 — **최종 판단은
사용자가 대시보드의 정의를 보고 한다.**

| 양식 항목                                                                     | 초안 답                                                                               |
| ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| 웹사이트 콘텐츠 (Website content)                                             | 해당 — 사용자가 누른 YouTube 탭의 영상 제목 · 재생 시점을 39page 확인 화면으로 넘긴다 |
| 웹 기록 (Web history)                                                         | 해당 여부 검토 필요 — 탭 주소에서 영상 ID 만 읽고, 방문 기록을 모으지 않는다          |
| 그 밖의 항목(개인 식별 · 건강 · 금융 · 인증 · 위치 · 개인 통신 · 사용자 활동) | 해당 없음                                                                             |
| 판매하지 않음 · 목적 밖 사용 없음 · 신용 평가 등에 쓰지 않음                  | 예 (세 항목 모두 확인)                                                                |
| 개인정보처리방침 주소                                                         | **TODO** — `EXTENSION_PRIVACY.md` 를 사용자가 웹에 게시한 주소                        |
