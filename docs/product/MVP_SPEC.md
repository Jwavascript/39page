## 1. 개요

39page는 음악 중심의 커스터마이징 웹 대시보드다.
사용자는 테마를 선택해 대시보드 외형을 바꾸고, YouTube로 음악을 재생하며,
시계·날씨 위젯과 도트 마스코트를 함께 본다.

프로토타입의 제품명은 **My Little Frequency** (`MLF`)다.

### F3. 음악 재생

**확정 사항 (v08 / v09)**

- 재생 소스는 **YouTube IFrame Player API 단독**이다. 플레이어 인스턴스는 **1개**다.
- `playerVars`: `controls:1`, `playsinline:1`, `rel:0`, `autoplay:0`.
  → **YouTube 기본 컨트롤을 그대로 노출한다.** 자체 탐색 바·볼륨 UI를 만들지 않는다.
  프로토타입 문구: `YouTube 공식 영상·컨트롤은 그대로 표시됩니다.`
- 자체 컨트롤은 **이전 곡 / 재생·일시정지 / 다음 곡** 3개뿐이다.
- 영상 영역은 16:9, 최소 200×200.
- 곡 전환은 `loadVideoById`(즉시 재생) / `cueVideoById`(대기)를 사용한다.
  플레이어를 재생성하지 않는다.
- `ENDED` 이벤트에서 다음 곡으로 진행한다. 큐 끝에 도달하면 정지하고 안내한다.
- **가시성 가드**: 영상 영역이 200×200 미만이거나 50% 이하로 보이면 재생을 막고
  재생 중이면 일시정지한다. 좁은 화면에서 드로어를 열면 먼저 일시정지한다.
  → 200×200 은 공식 요구사항, 50% 는 자체 휴리스틱이다 (아래 · §8.1).
  → 구현(M3-4): 판정은 순수 함수, 재평가 통지는 `IntersectionObserver` 와
  드로어의 **사전 통지** 두 경로다. 가려져서 멈춘 뒤 다시 보여도 **자동으로
  재생하지 않는다.** 거절된 재생 요청은 큐를 바꾸지 않고, 드로어가 가린
  경우에는 드로어가 직접 안내한다 (ADR 0011).
- 처리해야 하는 플레이어 이벤트: `onReady`, `onStateChange`,
  `onAutoplayBlocked`, `onError`.
- 상태 메시지는 `role="status"` `aria-live="polite"` 영역에 출력한다.
  오류·경고는 `warning` 변형으로 표시한다.
  → 구현(M3-3): 그 영역에는 **의도적으로 띄운 안내만** 담는다. 재생·버퍼링
  같은 전이 상태는 `NOW PLAYING` 부제에 적는다. 라이브 리전에 넣으면 곡마다
  서너 번씩 읽힌다 (ADR 0010).
- 재생 실패 시 `YOUTUBE에서 열기 ↗` 외부 링크를 노출한다
  (`target="_blank"`, `rel="noopener noreferrer"`).
  → 구현(M3-5): 레퍼런스와 같이 **곡을 고른 뒤에는 항상** 보인다. 오류일
  때만 띄우면 재생이 깨지는 순간 링크가 새로 나타나 레이아웃이 흔들린다.
  주소는 영상 ID 를 다시 검증해 만든다 (ADR 0012).

**공식 정책 확인 결과 (M3-0 준비)**

상세와 출처는 `docs/architecture/SYSTEM_DESIGN.md` §8.1 에 있다.

- **API 키가 필요 없다.** IFrame API 는 키 없이 동작한다. (TODO 해소)
- **최소 200×200 은 공식 요구사항**이다. 16:9 에서 480×270 이상은 권장이다.
- 위의 "50% 초과 노출"은 **공식 기준이 아니라 프로토타입에서 가져온 우리
  휴리스틱**이다. 공식 정책이 금지하는 것은 사용자가 보고 있지 않은 곳에서의
  재생(개발자 정책 III.I.9)이며 수치 기준은 없다. 임계값은 조정할 수 있고,
  가려지면 멈춘다는 원칙은 바꿀 수 없다.
- 드로어를 오버레이가 아닌 형제 열로 둔 것은 "플레이어를 가리지 말라"는
  III.I.6 · III.I.4 와도 맞는다.
- `onError` 코드: 2(잘못된 파라미터) · 5(HTML5 재생 불가) · 100(영상 없음) ·
  101·150(임베드 불가) · 153(`Referer` 헤더 없음).
- 153 때문에 referrer 정책이 재생에 영향을 준다. 승인된 레퍼런스는
  `strict-origin-when-cross-origin` 을 선언하지만 제품 `index.html` 에는 없다.

멈추고 `YOUTUBE에서 열기 ↗` 를 띄운다. 그 동작을 유지한다.

`SYSTEM_DESIGN.md` §8.1 · §6.1 에 적었다.

**오류 처리 확정 (M3-5, 2026-11-03)** — 상세는 ADR 0012

| 종류                | 코드      | 안내가 가리키는 행동       |
| ------------------- | --------- | -------------------------- |
| `invalid-parameter` | 2         | 링크를 다시 등록           |
| `not-playable`      | 5         | YouTube 에서 열기          |
| `not-found`         | 100       | (알림만)                   |
| `embed-not-allowed` | 101 · 150 | YouTube 에서 열기          |
| `referrer-missing`  | 153       | (알림만)                   |
| `api-unavailable`   | —         | 네트워크 확인 후 ▶ 를 다시 |
| `unknown`           | 그 외     | 다음 곡 직접 선택          |

- 번호는 안내 끝에 함께 보여준다. 사용자가 검색하거나 알려줄 수 있는 유일한
  단서다. 스크립트 로드 실패에는 번호가 없다.
- **API 로드 실패는 재시도할 수 있다.** 실패한 `<script>` 를 치우고 시도를
  버리므로, ▶ 를 다시 누르면 새 요청이 나간다. 문서에 스크립트는 언제나
  하나뿐이다.
- **자동재생 차단**은 오류가 아니다. 어댑터가 낙관적으로 세운 `loading` 만
  `idle` 로 되돌려 토글이 ▶ 를 보여주게 하고, 사용자가 다시 요청할 수 있게
  한다.
- 어떤 오류에서도 **자동으로 다음 곡으로 넘기지 않는다** (M3-0.7).
- 영상 로딩 전 안내(`.video-placeholder`)는 어댑터 소유 영역의 **형제**이고
  `v-if` 가 아니라 클래스로 숨긴다 (ADR 0002 · 0012).

### F4. 플레이리스트 관리

**확정 사항 (v08) — 데이터 모델**

```
Playlist { id: string, name: string (최대 60자), tracks: Track[] }
Track    { id: string, source: 'youtube', videoId: string, title: string }
```

- 초기 상태: `MY RECORDS` 플레이리스트 1개, 트랙 0개.
- **플레이리스트 조작**: 생성 / 이름 수정 / 삭제 / 선택.
  - 삭제는 확인을 받는다. **마지막 플레이리스트는 삭제할 수 없다.**
  - 이름은 60자로 자른다. 빈 이름은 거부한다.
- **트랙 조작**: 추가 / 위로 / 아래로 / 삭제. 삭제는 확인을 받는다.
  - 목록 경계에서 이동 버튼은 비활성화된다.
  - 재생 중인 트랙을 삭제하면 재생을 멈추고 안내한다.
    → 구현(M3-5): Record Library 가 **사실만** 알리고
    (`trackRemoved(trackId)`), 멈출지는 Playback Coordinator 가 정한다.
    **큐는 바꾸지 않고** 다음 곡으로 자동 전환하지도 않는다 (ADR 0012).
- **트랙 추가**: 모달에서 YouTube URL + 곡 이름(선택) 입력.
  - 이름을 비우면 `YouTube · <videoId>`로 표시한다.
  - 이름 최대 100자.
- **URL 파싱**: 다음을 허용하고 11자 영상 ID(`^[A-Za-z0-9_-]{11}$`)를 추출한다.
  - 호스트: `youtube.com`, `music.youtube.com`, `youtube-nocookie.com`, `youtu.be`
    (`www.` / `m.` 접두사 허용)
  - 경로: `/watch?v=`, `/shorts/`, `/embed/`, `/live/`, `youtu.be/<id>`
  - 실패 시 인라인 오류: `올바른 YouTube 영상 링크를 입력해주세요.`
- **큐 모델**: 재생 시작 시점에 플레이리스트 트랙을 **스냅샷 복사**한다.
  큐는 `queue`, `queueListId`, `queueIndex`로 추적한다.
  → 재생 중 라이브러리를 편집해도 큐가 즉시 흔들리지 않는다.

**트랙 등록·편집 구현 완료 (M2-3)**

- `＋ YouTube 링크 추가` → 드로어 안 인라인 폼 (URL 필수 + 곡 이름 선택).
  `parseYouTubeVideoId()`(M1-1)로 검증한다. 파서를 새로 만들지 않았다.

### F5. Record Library

**확정 사항 (v08 / v09)**

- **오버레이가 아니다.** 넓은 화면에서 `.workspace` 그리드의 형제 열로 열린다
  (폭 **340px**). 영상을 가리지 않는다.
- 좁은 화면(`max-width: 1100px`) 또는 세로 모드에서는 스테이지를 **대체**한다.
  이때 영상이 숨겨지므로 **열기 전에 일시정지**한다.
- 여는 방법: LP/카세트 클릭, 헤더의 `◉ 라이브러리` 버튼.
- 닫는 방법: `×` 버튼, `ESC`.
- 구성: 헤더(`RECORD LIBRARY` / `COLLECTION / YOUTUBE ONLY`) ·
  본문(링크 추가, 새 목록, `YOUR PLAYLISTS`, 플레이리스트 목록,
  선택 목록의 `TRACKS`, 전체 재생/이름 수정/삭제, 트랙 목록) · 푸터 안내.
- 플레이리스트 행은 [선택 버튼 | ▶ 재생 버튼] 구조다. 트랙이 없으면 ▶는 비활성.
- 접근성: 드로어에 `aria-hidden` 토글, 트리거에 `aria-expanded` 토글.
  열면 닫기 버튼으로 포커스 이동, 닫으면 트리거로 포커스 복귀.
- 트랙을 재생하면 드로어는 자동으로 닫힌다.

**UI 구현 완료 (M2-2)**

- 드로어는 `.workspace` 그리드의 형제 열(340px)이다. 오버레이가 아니다.
- 1100px 이하에서는 스테이지를 대체한다 (`display: none`, 언마운트 아님).
- 데크 트리거는 SVG 밖의 네이티브 `<button>` 이다. DeckArt SVG 는 수정하지
  않았다. `aria-expanded` · `aria-controls` 로 드로어와 연결한다.
- 포커스 가둠을 구현하지 않았으므로 `aria-modal` 을 선언하지 않는다.
- 레퍼런스의 `＋ YouTube 링크 추가`, 행 오른쪽 `▶`, `목록 전체 재생` 은
  만들지 않았다. 동작하는 기능이 아직 없어 동작하지 않는 버튼이 된다
  (M2-3 / M3).
- `prompt()` · `confirm()` 은 드로어 안의 인라인 폼과 확인 영역으로 대체했다.

드로어 제목은 두 테마 모두 `RECORD LIBRARY` 다. 데크 아래 안내 문구만
테마별로 다르다 (`믹스테이프 보관함`).

### F6. 시계 위젯

**확정 사항 (v08)**

- **도트 매트릭스 SVG 시계.** 숫자만 도트로 렌더링한다. 나머지 라벨은 모노스페이스 텍스트.
- 글리프: 숫자 `0`–`9`는 5×7, `:`는 1×7 비트맵.
- 렌더링: 도트는 `<circle r="3.1">`, 간격 9.3, 글자 간 추가 간격 13.
  꺼진 도트도 함께 그린다(`.time-off`, opacity .18) — 전광판 질감.
- 시간 형식: **12시간제 `HH:MM`** (시 2자리 zero-pad), AM/PM은 별도 표시.
- 날짜 라인: `MON  NOV 02  2026` (요일·월 대문자, 공백 2칸 구분).
- 지역 라벨: `SEOUL, KOREA`. 타임존 `Asia/Seoul` **하드코딩**.
- 갱신 주기: **15초**. 분이 바뀔 때만 다시 그린다.
- `aria-label`에 현재 시각을 넣는다.

**구현 완료 (M4-1, 2026-11-03)**

- 글리프와 기하 상수(`r=3.1` · 간격 9.3 · 글자 간 13)를 레퍼런스에서 그대로
  옮겼다. 테스트가 **문자 단위로** 비교한다.
- 배치 계산은 순수 함수(`dotGlyphs.ts`)다. 렌더러는 시간을 모른다.
- 15초 갱신 + **탭 복귀 시 즉시 갱신**. 브라우저가 백그라운드 타이머를 분
  단위까지 늦추므로, 그것이 없으면 돌아왔을 때 지난 시각이 보인다.
- `aria-label` 은 `현재 시각 AM 10:15` 다. 레퍼런스는 `01:15` 만 넣는데 그대로
  두면 오전·오후를 알 수 없어, 작성된 의도를 따라 기간과 맥락을 더했다
  (ADR 0004 와 같은 판단).

**확정 (M4-1)**

| 항목        | 결정                                                               |
| ----------- | ------------------------------------------------------------------ |
| 타임존      | **`Asia/Seoul` 고정.** 사용자 설정으로 노출하지 않는다             |
| 12/24시간제 | **12시간제 고정.** 승인된 디자인의 표기이고 선택 컨트롤이 없다     |

### F7. 날씨 위젯

**확정 사항 (v08) — 레이아웃만**

- 구성: 아이콘 · 온도 · 설명 · 최고/최저. 최고/최저는 오른쪽 정렬.
- 프로토타입 값은 **고정 예시**다: `☁`, `18°`, `조금 흐림`, `H 22° / L 12°`.
  하단 주석에 `WEATHER / 디자인 예시 · 실제 API 연결 전`으로 명시되어 있다.

**확정 및 구현 완료 (M4-2, 2026-11-03) — 상세는 ADR 0013**

| 항목        | 결정                                                                                |
| ----------- | ----------------------------------------------------------------------------------- |
| 제공자      | **Open-Meteo.** API 키가 없고 CORS 가 열려 있다. npm 패키지를 추가하지 않았다       |
| API 키 보호 | **해당 없음.** 키가 필요 없는 제공자를 골라 문제를 없앴다. 서버·프록시 불필요       |
| 위치        | **서울 고정** (`37.5665, 126.978`). 위치 권한을 요청하지 않는다                     |
| 위치 표시   | `.weather-note` 에 `WEATHER / SEOUL · OPEN-METEO` — 새 UI 없이 위치와 출처를 밝힌다 |
| 갱신 주기   | 성공 뒤 **15분**, 실패 뒤 **2분**. 캐시 5분                                         |
| 실패 표시   | 기온 자리에 `--°`, 설명에 사정. **이전 값을 남기지 않는다**                         |
| 아이콘      | WMO 코드 → 한 글자 글리프. 코드 2 는 승인된 예시(`☁ 조금 흐림`)와 같다              |
| 단위        | **°C 고정**                                                                         |

- **응답을 믿지 않는다.** 기온·코드·최고·최저 중 하나라도 유한한 숫자가
  아니면 `malformed` 로 보고 부분적으로 채우지 않는다.
- 실패 사유를 `network` · `http` · `malformed` 로 갈라 다른 문구를 쓴다.
- `navigator.geolocation` 을 쓰는 코드가 **아예 없다** (정적 검사로 고정).

### F9. 설정 로컬 저장

**확정 사항 (v08 / v09)**

- 저장 매체는 **`localStorage`**다.
- 저장 대상은 **두 갈래로 분리**되어 있다.

  | 내용                                                  | 프로토타입 키                 | 구현된 키        |
  | ----------------------------------------------------- | ----------------------------- | ---------------- |
  | 라이브러리 (플레이리스트, 트랙, 선택 목록, 현재 트랙) | `mlf_mono_vinyl_v08`          | `39page.library` |
  | 선택한 테마                                           | `mlf.design.theme.preview.v1` | `39page.theme`   |

  > **구현과의 차이 (2026-11-06 확인).** 프로토타입의 "현재 트랙" 은
  > `LibraryData` 에 **넣지 않았다.** 재생 큐와 현재 트랙은 의도적으로 세션
  > 상태다 (`SYSTEM_DESIGN.md` §6.1). 저장되는 것은 플레이리스트·트랙·선택
  > 목록뿐이고, 이 범위가 M8 백업의 대상과 같다.

- 읽기는 **방어적으로** 수행한다 (v08 `safeLoad`). 이 패턴을 유지한다.
  - `JSON.parse` 실패 → 초기 상태로 복구
  - `lists`가 배열이 아니거나 비어 있으면 초기 상태
  - 각 항목의 `name`(문자열)·`tracks`(배열) 검증 후 불량 항목 제거
  - `selected`가 존재하지 않는 id면 첫 번째 목록으로 보정
- 쓰기는 `try/catch`로 감싼다 (v09 테마 저장이 그렇게 한다).

**확정 사항 (M1-1 구현)**

제품 저장 키는 다음으로 고정한다. 프로토타입 키는 쓰지 않는다.

| 내용        | 제품 키          |
| ----------- | ---------------- |
| 라이브러리  | `39page.library` |
| 선택한 테마 | `39page.theme`   |

- 키에 버전을 넣지 않는다. 스키마 버전은 저장 객체 안의 `version` 필드로 관리한다.
- 저장 객체 형태: `{ version, data }`
- 검증·마이그레이션 실패 시 **기존 저장 데이터를 삭제하거나 덮어쓰지 않는다.**

상세: `docs/architecture/SYSTEM_DESIGN.md` §7.1

## 4. 비기능 요구사항

**확정 사항 (프로토타입에서 추출)**

- **언어**: 한국어 UI (`<html lang="ko">`). 라벨·장식 문자열은 영문 대문자 모노스페이스.
- **색 구성**: 다크 전용 (`color-scheme: dark`). 두 테마 모두 다크다.
- **반응형**: 브레이크포인트 `1100px`(레이아웃 1열 전환 + 드로어 전체화면),
  `730px`(테마 전환 버튼 축소), `650px`(여백·폰트 축소), `600px`(마스코트 축소).
  최대 폭 1920px.
- **접근성**
  - 포커스 링: `2px solid #f0e2c8`, `outline-offset: 3px` (`:focus-visible`)
  - 최소 터치 타깃: 주요 컨트롤 42px (메인 재생 51px), 드로어 pill 36px
  - 상태 안내는 `role="status"` `aria-live="polite"`
  - 모달은 `role="dialog"` `aria-modal="true"` + `aria-labelledby`
  - 토글 버튼에 `aria-pressed`, 드로어 트리거에 `aria-expanded`
  - 모든 장식 SVG에 `role="img"` + 한국어 `aria-label`
  - 키보드: `ESC`로 모달 → 드로어 순서로 닫기, SVG 컨트롤은 `Enter`/`Space` 처리
- **모션**: `prefers-reduced-motion: reduce`에서 모든 회전·호흡 애니메이션과
  트랜지션을 비활성화한다.
- **보안**: `<meta name="referrer" content="strict-origin-when-cross-origin">`,
  외부 링크는 `rel="noopener noreferrer"`.

  않는다** (ADR 0007).
