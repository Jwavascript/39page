### M0 — 프로젝트 초기화 (완료)

Vue 3 + TypeScript + Vite + Pinia 스캐폴딩, Vitest/ESLint/Prettier 구성,
디렉터리 구조와 문서 틀. 기능 구현 없음.

### M1 준비 — 디자인 레퍼런스 반영 (완료)

`design/references/`의 프로토타입 2종을 검토해 MVP 스펙·시스템 설계·테마 시스템
문서를 갱신하고, 확정된 결정 3건을 ADR로 기록했다. **UI 구현은 포함하지 않았다.**

### M1 — 앱 셸 · 테마 토큰 · 플레이어 영속성 골격 (미착수)

테마를 전환해도 YouTube 재생이 유지되는 **구조**를 세우는 것이 목표다.
플레이어 iframe은 부모가 바뀌기만 해도 재로드되므로, 이 제약을 만족하는 DOM
골격을 가장 먼저 확정한다.

상세 작업 목록은 [`docs/development/IMPLEMENTATION_PLAN.md`](../development/IMPLEMENTATION_PLAN.md) 참조.

## 범위 외

로컬 음악 재생, 집중 모드, AI 에이전트, 소셜 기능은 MVP에서 제외한다.

위젯 추가·삭제·이동·크기 변경과 개별 위젯 스킨 조합은 MVP 범위 밖이지만,
나중에 구조를 다시 쓰지 않도록 M1에서 최소 확장 지점만 마련한다
(`docs/decisions/0003-widget-registry-host.md`).
