### M0 — 프로젝트 초기화 (완료)

Vue 3 + TypeScript + Vite + Pinia 스캐폴딩, Vitest/ESLint/Prettier 구성,
디렉터리 구조와 문서 틀. 기능 구현 없음.

### M1 준비 — 디자인 레퍼런스 반영 (완료)

`design/references/`의 프로토타입 2종을 검토해 제품·아키텍처 문서를 갱신하고,
확정된 결정 3건을 ADR로 기록했다. Git 초기 기준점을 `main`에 커밋하고
MVP 범위를 정정해 확장 항목을 백로그로 분리했다. **UI 구현은 포함하지 않았다.**

### M1 — 앱 셸 · 두 테마 · 테마 전환 · Widget Host · 플레이어 영속성 구조

테마를 전환해도 **플레이어 인스턴스와 DOM 구조가 유지되는지** 검증하는 것이
목표다. 플레이어 iframe은 부모가 바뀌기만 해도 재로드되므로, 이 제약을 만족하는
DOM 골격을 가장 먼저 확정한다.

M1은 `FakePlayerAdapter` 기반의 **구조 검증**에 집중하고, 실제 YouTube IFrame API
동작은 M3로 분리한다.

- M1-0 선행 정리 (테마 키 통일) — 완료
- M1-1 공유 타입과 저장 계층 — 완료
- M1-2 테마 토큰 체계 — 완료
- M1-3 테마 store와 전환 — 완료
- M1-4 안정 셸과 Widget Host — 완료
- M1-5 플레이어 영속성 구조 ★ — 완료
- M1-6 데크 아트와 마스코트 — 완료

### M2 — Record Library와 플레이리스트 관리

- M2-1 Library Store와 영속화 — 완료 (데이터 계층만, 화면 변경 없음)
- M2-2 Record Library 드로어 — 완료
- M2-3 트랙 등록과 편집 — 완료

플레이리스트 CRUD, 트랙 추가·순서 변경·삭제, 340px 드로어, 추가 모달, 토스트.

### M3 — YouTube 실제 재생과 연속 재생

M3-0 선행 결정과 정책 확인 — 완료 · M3-1 `YouTubeIFramePlayerAdapter` — 완료 ·
M3-2 큐 진행과 라이브러리 연결 · M3-3 트랜스포트 UI와 상태 메시지 ·
M3-4 가시성 가드와 드로어 연동 · M3-5 오류·예외 처리.

M3-0 결정: 반복·셔플·자체 볼륨 UI 는 **MVP 제외**, 재생 불가 영상은
정지·안내, `origin` 은 현재 페이지 origin, referrer 메타 명시 선언,
큐 연결은 애플리케이션 계층이 조립. `PlayerAdapter` 에는 **최소한의 이벤트
전달 계약**만 더한다 (ADR 0008).
공식 IFrame API 요구사항은 `SYSTEM_DESIGN.md` §8.1 에 정리했다.

### M4 — 날씨 위젯 및 마스코트 상태별 애니메이션

시계 위젯, 날씨 위젯(제공자 확정 선행), 데크 회전 애니메이션,
마스코트 호흡 애니메이션과 테마별 메시지, `prefers-reduced-motion` 검증.

### M5 — UX, 반응형, 접근성, 통합 테스트 및 안정화

브레이크포인트 정교화, 좁은 화면 드로어 동작, 접근성 감사,
종합 통합 테스트, 오류·빈 상태 문구, 성능 점검.
