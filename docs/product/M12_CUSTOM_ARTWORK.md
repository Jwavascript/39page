# M12 — Custom Artwork & Now Playing UX

- 상태: **M12-1 설계 확정** (2026-11-15) → M12-2 ~ M12-5 구현 · 검증 결과를 §9 에 덧붙인다.
- 기술 설계: [`../architecture/ARTWORK_DESIGN.md`](../architecture/ARTWORK_DESIGN.md) · ADR 0032 · 0033 · 0034
- 기준: M11-7C (`m11-7c-moments-track-ux`, 마지막 커밋 `1db699e` — 가로 화면 보관함 닫기 위치 수정 포함)

M12 는 원래 "도트 마스코트 상세 · 애니메이션" 이었다. 사용자 지시로 **곡별 Custom Artwork 와 음악 감상 중심 Now
Playing** 으로 다시 정의한다. 캐릭터 기능 확장이 아니다 — 마스코트(Companion) 패널은 없어진다.

## 1. Now Playing 카드

영상 **바로 아래**의 카드 하나가 지금 곡의 얼굴 · 정보 · 조작을 모두 갖는다.

```text
┌──────────┬──────────────────────────────┐
│          │ NOW PLAYING · 2 / 5           │
│ ARTWORK  │ 곡 제목 (두 줄까지)            │
│ (정사각) │ 재생 중 · 1:23 · 목록 이름      │
│          │ ⏮  ⏯  ⏭      YOUTUBE에서 열기 ↗│
│          │ (안내 · 경고 — 있을 때만)       │
└──────────┴──────────────────────────────┘
```

- 영상 위에 있던 제목 · 부제 · 재생 조작은 **카드로 옮긴다** (영상 위에는 남지 않는다 — 같은 곡 정보와 버튼을 두 번 보이지 않는다).
  YouTube iframe 안의 제목 · 공식 컨트롤은 그대로다. 데크 아트에 그려진 키(▶ / ■)는 테마 아트의 일부로 남는다 (ADR 0017).
- 재생 위치는 지금 초(`1:23`)만 보인다 — 플레이어 계약에 길이(duration)가 없다. 길이를 추정해 적지 않는다.
- 상태 안내(라이브 리전, 경고 색)는 카드 안의 한 줄이다. 비어 있으면 자리를 차지하지 않는다.
- 그림을 누르면(현재 곡이 목록의 트랙일 때) 그 트랙의 **앨범아트 설정**이 열린다. 목록 밖 영상이면 누를 수 없다.
- 움직이는 그림(GIF)일 때만 "움직임 멈춤 / 재생" 작은 단추가 그림 모서리에 선다 (ARTWORK_DESIGN §5).

## 2. 대시보드 배치

| 화면                               | 배치 (`grid-template-areas`)                                                                                                                                           |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 넓은 화면 (> 1100px)               | `deck player clock` / `deck player weather` / `playlist player moments` — 3열 유지. 카드는 플레이어 위젯 안 영상 바로 아래, Moments 는 시계 · 날씨 아래 남는 높이 전부 |
| 중간 (701 ~ 1100px)                | `deck playlist` / `player player` / `moments moments` / `clock weather` — 카드는 영상과 같은 폭 (플레이어 안)                                                          |
| 한 열 (≤ 700px, 세로 폰)           | `deck`(작은 띠) / `player`(영상 → 카드) / `moments` / `playlist` / `clock` / `weather` — 지시서 세로 그림과 같다                                                       |
| 낮은 가로 (높이 ≤ 560 · 폭 ≤ 1100) | `player moments` / `player playlist` / `deck playlist` / `clock weather` — 영상이 첫 화면에, 카드는 그 아래                                                            |

- 배치는 폭 · 높이 미디어 쿼리로 정한다 (방향 하나로 정하지 않는다). 영상은 어느 배치에서도 202px(테두리 포함) 이상이다.
- **카드는 플레이어 위젯 안**이다 (ADR 0032 결정 2) — 따로 된 그리드 칸으로 두었을 때 실제 Chrome 에서 영상과 카드 사이가 81 ~ 165px
  벌어졌다. 위젯 안에서는 어느 배치에서도 14px 다.
- 카드는 폭에 따라 **컨테이너 쿼리**로 그림 크기를 줄인다: 카드 폭 ≥ 440px → 그림 148px, 그 아래 → 112px, 320px 폭 화면(카드 ≈ 286px) → 88px 와 제목 두 줄. 제목 칸이 120px 아래로 줄지 않게 한다.

### 보관함이 열렸을 때 (M11-7B 배치 C 유지)

같은 카드 **인스턴스**가 재생 띠에 함께 선다 — 복제 · 새 마운트가 없다.

| 배치  | 재생 띠                                                                                                                         |
| ----- | ------------------------------------------------------------------------------------------------------------------------------- |
| strip | `player moments` — 플레이어 안에서 [영상 \| 작은 카드(그림 72px · 제목 · 조작)], 그 오른쪽 이 곡 Moments (1000px 이하면 아래로) |
| stack | 영상 → 한 줄 카드(그림 숨김 · 제목 · 조작) → 이 곡 Moments                                                                      |
| side  | stack 과 같다 (왼쪽 열)                                                                                                         |

## 3. 앨범아트 설정 (M12-3)

입구: **보관함 → 음악 → 곡의 "관리" → 🖼 앨범아트**, 그리고 Now Playing 카드의 그림.

```text
┌ 앨범아트 — <곡 제목> ───────────────────── × ┐
│ [현재 그림 160px]   지금: YouTube 썸네일       │
│                                                │
│ ( ) YouTube 썸네일 사용                         │
│ ( ) 39page 기본 그림 사용                        │
│ ( ) 내 이미지 · GIF  [파일 고르기]  PNG·JPEG·WebP 5MB, GIF 12MB │
│      [새 그림 미리보기]  320×320 · 1.2 MB · GIF(움직임) │
│                                                │
│ 앨범아트 사용량 4.1 MB · 브라우저 여유 약 2 GB  │
│ 이 브라우저에만 저장됩니다 — 전체 백업(ZIP)으로 보관하세요 │
│                                [취소] [저장]   │
└────────────────────────────────────────────────┘
```

- 고르기만으로는 바뀌지 않는다. **저장**이 IndexedDB 트랜잭션을 마친 뒤에야 "저장했습니다" 를 보이고 카드가 바뀐다.
- 실패하면 이전 그림이 그대로이고, 이유를 대화상자 안에 적는다 (형식 · 크기 · 손상 · 용량 · 다른 탭 변경 · 곡이 지워짐 · 저장소 없음).
- 다른 곡의 재생 · 큐 · 위치는 바뀌지 않는다. 지금 곡이면 카드가 바로 바뀐다.
- 데이터 대화상자에 "앨범아트 저장 공간" 줄: 사용량 · 자산 수 · "쓰지 않는 그림 정리" · "이 브라우저에 오래 보관 요청"(`persist`).

## 4. 백업 · 공유 (M12-4)

데이터 대화상자의 백업 칸:

| 단추                         | 내용                                                                                                      |
| ---------------------------- | --------------------------------------------------------------------------------------------------------- |
| **전체 백업 (ZIP)** — 권장   | 플레이리스트 · Moments · 테마 · 앨범아트 이미지와 연결. 빠진 그림이 있으면 완료라 하지 않고 개수를 적는다 |
| JSON 백업 (앨범아트 제외)    | 기존 파일 그대로. 사용자 이미지가 있으면 "앨범아트는 들어가지 않습니다" 확인                              |
| 백업 가져오기 (.zip · .json) | ZIP: 검증 → 미리보기(앨범아트 포함) → 지금 것 먼저 받기 → 승인 → 단계 복원 → 섹션별 결과                  |

공유 (M12-4 구현): 데이터 · 백업 대화상자의 **SHARE** 칸 — 목록을 고르고 범위(목록 전체 / 한 곡)를 고른 뒤 "공유 파일 만들기".
Moments 넣기는 체크박스(기본 꺼짐, 넣을 개수 표시). 가져오기: 같은 칸의 "공유 파일 가져오기" → 미리보기 → 새 목록 / 기존 목록에
추가 · 같은 영상 건너뛰기 / 그래도 추가 · Moments 가져오기(들어 있을 때만). 설계 때는 보관함 목록 상세 · 곡 관리에 두려 했으나,
기능 사이 직접 의존을 늘리지 않고 백업과 한 곳에서 파일을 다루도록 대화상자로 모았다. 앨범아트 저장 공간(사용량 · 정리 ·
오래 보관 요청)도 같은 대화상자의 ARTWORK 칸이다.

할 수 없다 — 미검증으로 적는다.

## 6. 출시 판단 원칙

- 사용자 이미지 올리기(M12-3)는 **ZIP 전체 백업 · 복원(M12-4)이 같은 빌드에 있기 전에는 출시 가능으로 표시하지 않는다.**
- M11-7D(최종 UAT · 배포 준비)는 M12 뒤로 옮긴다 — 새 UI · 저장 구조 기준으로 다시 점검한다 (`ROADMAP.md`).

## 10. M12-6 UX Polish (2026-11-15, 로컬 구현)

- 보관함: 진입 의도별 목록/상세/Artwork/전체 Moments. 닫으면 하위 편집을 정리하고 미저장 파일·입력·구도는 폐기 확인한다.
  단순 옵션 변경은 취소로 폐기한다. 선택 목록과 마지막 탭, 저장된 그림, Moment 공유 초안은 유지한다.
- 모든 Artwork 옵션에 저장 전 미리보기. 사용자 이미지에는 Cover/Contain·가로/세로 위치·1–3배 확대·초기화·포인터 끌기.
  카드와 같은 정사각 비율, GIF 원본·포스터·모션 감소·화면 밖 정지·URL 해제를 유지한다.
- 제목 조회: 빠른 제출도 조회를 마치며 최대 4초, 실패 시 추가 가능. 수동 제목과 기존 저장 제목은 보호한다.
- 카세트 레이블: 실제 큐 출처 이름, 큐 없을 때 선택 목록, 출처 불명은 기존 문구. 한 줄 말줄임·전체 제목 접근성 제공.
- 목록/곡 관리 메뉴에서 기존 SharePanel로 정확한 공유 대상을 전달한다. Moments 포함은 기본 꺼짐이다.
- 연결의 `display`는 원본과 독립적이다. IndexedDB v1 유지, ZIP/공유는 v2 쓰기·v1/v2 읽기.
