### 확장이 다루는 정보

39page 확장은 **사용자가 확장 아이콘이나 단축키를 누를 때에만**, 그 순간 열려 있는 탭에서 다음을
읽습니다.

- 탭의 주소 — YouTube 영상 페이지인지, 어떤 영상인지(영상 ID) 확인하기 위해
- YouTube 플레이어가 띄운 영상의 제목과 지금 재생 시점 — "현재 Moment 저장" 을 누른 경우

누르지 않으면 어떤 탭도 읽지 않습니다. 다른 사이트나 방문 기록은 읽지 않습니다.

### 정보를 어디로 보내는가

읽은 영상 ID · 제목 · 재생 시점은 39page 의 확인 화면(`https://39page.com/#collect?…`)을 새 탭으로
열 때 **주소의 `#` 뒤**에 담깁니다. 주소의 `#` 뒤는 웹 서버로 전송되지 않습니다. 39page 는 그 화면에서
사용자가 "추가" 나 "Moment 저장" 을 누를 때에만 그 정보를 **이 브라우저의 저장소(localStorage)** 에
저장합니다. 메모는 그 화면에서 사용자가 직접 씁니다.

확장은 정보를 저장하지 않고, 어떤 서버로도 보내지 않으며, 네트워크 요청을 하지 않습니다.

### 공유 · 판매

정보를 판매하거나 제3자와 공유하지 않습니다. 광고 · 신용 평가 · 그 밖의 목적에 쓰지 않습니다.

### 제한적 사용 (Limited Use)

이 확장이 Chrome 확장 API 로 받는 정보의 사용과 전달은
[Chrome 웹 스토어 사용자 데이터 정책](https://developer.chrome.com/docs/webstore/program-policies/policies)의
제한적 사용 요건을 따릅니다. 정보는 위에서 설명한, 사용자가 누른 기능을 위해서만 씁니다.

### 지우기

39page 에 담은 곡과 Moment 는 39page 화면에서 지울 수 있고, 브라우저의 사이트 데이터를 지우면 모두
사라집니다. 확장을 제거해도 39page 에 이미 저장한 데이터는 남습니다.
