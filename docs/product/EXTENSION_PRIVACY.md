# 39page 개인정보처리방침

시행일: 2026년 11월 20일 (최초 시행 2026년 11월 18일)

## 목적과 처리 정보

39page Chrome 확장은 사용자가 아이콘이나 단축키로 실행한 YouTube 영상에서 URL의 영상 ID, 영상 제목, 현재 재생 시점을 읽습니다. 사용자가 입력한 Moment 메모와 플레이리스트 이름도 저장에 사용합니다. 패널이 열려 있는 동안 선택한 영상의 상태를 확인하며, 페이지가 바뀌면 저장 대상을 바꿀지 사용자에게 알립니다. 전체 방문 기록이나 다른 사이트의 내용을 자동으로 수집하지 않습니다.

선택적인 39page 사이트 접근 권한을 허용하면, 패널에서 이 브라우저의 39page 플레이리스트 이름·곡 수·선택 영상의 중복 위치와 Moments 시점을 조회합니다. 곡·Moment 저장은 사용자가 저장 버튼을 눌러야 수행합니다. 권한을 거부하면 수집 화면을 새 탭으로 열어 확인 후 저장할 수 있습니다. 권한은 Chrome 확장 설정에서 철회할 수 있습니다.

## 저장과 전달

확장은 chrome.storage 권한을 선언하지 않고 chrome.storage.sync/local에 수집 내용을 영구 보관하지 않습니다. 탭 세션·저장 요청·임시 메모는 확장 메모리에 존재하며 패널이나 브라우저를 닫으면 사라질 수 있습니다.

곡·목록·Moments·설정은 39page.com의 브라우저 localStorage에 저장합니다. 사용자 업로드 artwork는 IndexedDB에 저장합니다. 다른 프로필·다른 origin·다른 기기로 자동 동기화하지 않습니다. 확장 삭제만으로 39page 사이트 저장 내용이 삭제되지는 않습니다.

직접 저장은 숨은 확장 문서의 https://39page.com/bridge.html 웹페이지와 postMessage로 정보를 교환합니다. 이 정보는 브라우저 내 다른 문맥인 39page 웹페이지에 전달됩니다. 현재 소스에는 곡·메모·목록을 서버 API에 업로드하거나 계정에 동기화하는 기능이 없습니다. 웹페이지 코드가 받아 처리하는 사실까지 부정하는 전송 없음이라는 뜻은 아닙니다.

수집 화면에서는 영상 ID·제목·시점을 https://39page.com/#collect 뒤 fragment에 싣습니다. fragment는 HTTP 요청 대상에 포함되지 않지만 브라우저 주소·기록과 웹페이지 JS에서 보일 수 있습니다. 메모는 Collect URL에 넣지 않으며 새 화면에서 직접 입력합니다.

## 공유 링크와 이미지 카드

웹앱의 공유 기능으로 목록·곡·Moment를 링크로 공유하면, 사용자가 고른 내용(영상 ID와, 선택한 경우 곡 이름·목록 이름·Moment 시점·메모)을 압축해 https://39page.com/#share?v=1&d=… 형식 링크의 fragment에 담습니다. 링크는 39page 서버에 저장되지 않으며 fragment는 HTTP 요청 대상에 포함되지 않습니다. 다만 링크를 붙여 넣은 게시판·메신저와 링크를 가진 누구나 그 내용을 볼 수 있고, 브라우저 주소·기록과 웹페이지 JS에서도 보일 수 있습니다. 서버에 사본이 없으므로 이미 전달한 링크를 39page가 회수하거나 삭제할 수 없습니다. 공개하고 싶지 않은 메모는 링크에 넣지 마세요.

공유 링크를 열면 39page는 받는 사람의 브라우저에서 내용을 검증해 미리보기만 보여 주고, 받는 사람이 직접 누를 때만 그 브라우저의 39page 저장소(localStorage)에 저장합니다. 미리보기를 닫으면 주소에서 공유 fragment를 지웁니다. 곡 이름이 없는 링크는 받는 사람의 브라우저가 YouTube oEmbed로 제목을 조회하며, 이때 영상 ID와 통상적인 접속 정보가 YouTube에 전달될 수 있습니다.

이미지 카드는 사용자의 브라우저에서 목록·곡 이름, 선택한 Moment 시점·메모, 그리고 "내 앨범아트 넣기"를 켠 경우 사용자가 올린 앨범아트를 그린 PNG 이미지입니다. 클립보드로 복사하거나 파일로 저장할 뿐 39page 서버로 보내지 않습니다. 사용자가 이 이미지를 게시판 등에 올리면 그 서비스의 정책에 따라 공개됩니다. 올린 앨범아트의 권리는 사용자에게 있으니 공유 전에 확인해 주세요. 공유 링크에는 앨범아트가 들어가지 않습니다.

## 네트워크와 외부 서비스

- 39page.com 페이지·브리지·정적 자원을 요청할 때 Cloudflare 호스팅에 IP 주소·요청 경로·시간·브라우저 정보 같은 통상적인 HTTP 정보가 전달될 수 있습니다. 호스팅 서비스의 운영 로그와 네트워크 진단 정보는 해당 서비스의 정책과 설정에 따라 처리됩니다.
- 2026-11-17 운영 응답에는 Cloudflare NEL/Report-To 헤더가 있습니다. 지원 브라우저가 네트워크 오류 보고를 Cloudflare의 a.nel.cloudflare.com에 보낼 수 있습니다. 앱 분석 SDK가 없는 것과 호스팅의 네트워크 진단 보고는 구분합니다.
- 확장 패키지는 원격 폰트·분석 SDK·광고 SDK를 포함하지 않습니다. 확장 탭에서 읽은 내용을 분석 서버에 전송하는 코드도 없습니다.
- 웹앱에서 음악을 재생하면 YouTube iframe/API, 썸네일을 표시하면 i.ytimg.com, 제목 자동 조회를 실행하면 YouTube oEmbed에 요청합니다. 영상 ID와 통상적인 접속 정보가 해당 서비스에 전달될 수 있습니다. 외부 서비스는 자체 정책에 따라 데이터를 처리합니다.
- 웹앱 날씨 위젯은 Open-Meteo에 고정 좌표의 날씨를 요청합니다. 사용자의 GPS 위치를 요청하지 않습니다. 숨은 저장 브리지는 플레이어·날씨 위젯을 구동하지 않습니다.

## 이용 제한과 제공

이 구현에는 사용자 수집 내용을 판매하거나 광고·신용 평가에 사용하는 기능이 없습니다. 위에 설명한 웹호스팅·외부 리소스 요청, 사용자가 직접 실행한 파일 내보내기·가져오기와 공유 링크·이미지 카드 외에, 서버 기반 공개 공유·클라우드 계정 동기화를 제공하지 않습니다. 메모에 민감한 개인정보를 적지 않도록 주의해 주세요.

Google API와 Chrome 확장 API를 통해 받은 정보의 사용 및 전달은 [Chrome Web Store 사용자 데이터 정책](https://developer.chrome.com/docs/webstore/program-policies/policies)의 Limited Use 요건을 준수합니다. 기능 제공에 필요한 목적으로만 사용합니다.

## 보관·백업·삭제

로컬 데이터는 사용자가 삭제하거나 브라우저가 사이트 데이터를 지울 때까지 보관됩니다. 곡·목록·Moments는 39page UI에서 삭제할 수 있습니다. 브라우저의 39page.com 사이트 데이터를 삭제하면 localStorage와 IndexedDB의 내용이 삭제되므로 먼저 백업하세요. 확장 제거·재설치는 웹앱 데이터 삭제 수단이 아닙니다.

39page의 데이터 관리 기능에서 JSON/이미지 포함 ZIP 백업을 내보내고 가져올 수 있습니다. 내보낸 파일에는 메모·목록·이미지 등이 포함될 수 있으므로 직접 관리하고 삭제해야 합니다. 서버에 별도 사본이 없는 로컬 데이터는 백업 없이 삭제하면 복구할 수 없습니다.
