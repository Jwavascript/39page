## 실제 Chrome 확인

[`check/share-entry.mjs`](share-entry-results/check/share-entry.mjs) — 로컬 빌드 · 격리된 임시 프로필 · 합성 데이터. 앨범아트는
페이지 안 캔버스로 만든 합성 그림을 앱의 설정 화면으로 올렸다. 결과 [`real-chrome-share-entry.json`](share-entry-results/real-chrome-share-entry.json)
**20/20 통과**.

- 두 아이콘: 44×44, 두 테마 × 1440 · 390px 에서 화면 안 · 가로 넘침 없음. 재생 전에는 카드 아이콘이 없다.
- 카드 아이콘 → 지금 목록 · 지금 곡, 데크 아이콘 → 지금 목록 전체. 목록을 바꾸면 데크 아이콘도 그 목록.
- 카드: J카드 · LP 뒷면 · 싱글(두 테마) · 영수증(두 테마)에 그림, 끄면 기본 그림으로 다시 그림, 그림 없는 대상은 고르는 칸이 없다.
- 실제 YouTube 가 합성 영상 ID 를 거절(오류 150)하면 안내 아래에 YouTube 링크(새 창 · `noopener noreferrer`)가 선다.
  처음 구현(플레이어 상태 `error` 로 판단)에서는 YouTube 가 오류 뒤 상태를 또 보내 링크가 사라졌다 — 안내의 출처로 판단하게 고치고
  같은 순서를 흉내 내는 단위 시험을 더했다.

화면: `dashboard-*.png`(두 테마 × 두 폭), `archive-strip-1440.png`(보관함을 연 띠 · 오류 링크). 카드: `card-*.png`.

## 확인하지 못한 것

- 실제 게시판에 그림이 든 카드를 올렸을 때의 재압축 · 링크 걸기.
- macOS · Android 글꼴, Safari · Firefox 의 `createImageBitmap` · 클립보드 이미지.
- 움직이는 GIF 의 첫 장면은 단위 시험(포스터를 넘김)으로만 봤다 — 실제 GIF 를 올린 확인은 하지 않았다.
