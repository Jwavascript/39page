# 0027. M11 정보 구조 — 대시보드는 그대로 두고, 라이브러리와 Moments 를 한 "보관함" 의 두 탭으로, 데이터는 헤더의 대화상자로

- 상태: **채택 — C안 (사용자 결정, 2026-11-12). M11-2 에서 골격 구현.** 실기기 확인 전이다 (아래 "보완 (M11-2)").
  남은 선택지는 `M11_UX_DESIGN.md` §10
- 관련: **ADR 0002** (플레이어 영속), **ADR 0011** (가시성 가드), **ADR 0016** (플레이리스트 표면), **ADR 0018**
  (백업), **ADR 0019 · 0021** (Moments), `docs/product/M11_UX_DESIGN.md`, 시안 `design/mockups/m11-1/index.html`

## 배경

실사용 · 외부 테스트(Claude for Chrome)에서 첫 방문자가 백업을 찾지 못했고(플레이리스트 편집 드로어 맨 아래에만
있다), 데스크톱 Moments 목록은 1~2행만 보이며, 라이브러리와 Moments 가 서로를 모른다. 헤더에는 이름 있는 입구가
없다. 자세한 목록 · 근거 등급은 `M11_UX_DESIGN.md` §1.

## 결정 (제안)

1. **역할 넷, 표면 셋.** Dashboard(그대로) · **보관함 서랍** (탭 "음악" · "Moments") · **데이터 대화상자**.
2. **헤더에 이름 있는 입구 셋** — "♪ 음악" · "◆ Moments" · "⇩ 데이터". 모든 폭에서 글자 이름을 남긴다. 대시보드
   안의 입구(타일 · "모두 보기")도 같은 서랍 · 같은 탭으로 간다.
3. **보관함이 열린 동안 데스크톱 그리드를 CSS 로만 바꾼다** — 데크 · 셸프 · 마스코트 · 정보 열을 감추고(지우지
   않는다) 플레이어(≥360px)와 보관함만 둔다. 플레이어 노드는 움직이지 않는다 (ADR 0002 금지 목록 준수).
4. **모바일은 1열 대시보드**, 보관함은 **플레이어를 위에 남긴 채** 그 아래를 채우는 시트 — 16:9 플레이어가 360px
   폭에서 202px 로 가시성 하한(200px)을 지킨다 [실기기 확인 필요].
5. **대시보드의 Moments 위젯은 "이 곡의 Moments" 미리보기**(최대 3행 + 빠른 저장 + 모두 보기)로 줄이고, 수정 · 삭제 ·
   검색은 보관함에서만 한다.
6. **데이터는 독립, 탐색은 통합** — Moment 저장 형식 · 키를 바꾸지 않는다. 곡 ↔ Moments 연결은 표시 계층에서
   `videoId` 로 잇는다.
7. **백업은 `BackupPanel` 을 데이터 대화상자로 옮겨 붙인다** — 내보내기 · 가져오기 · 보호 로직은 바꾸지 않는다.
8. **Moments 대량 표시는 묶음 접기 + 30묶음씩 점진 표시**, 페이지 번호 없음, 가상 스크롤은 5,000개 실측 뒤.

## 결과

- 헤더 · 보관함 서랍 · 그리드 상태 · 데이터 대화상자 · Moments 위젯 축소가 M11-2 ~ M11-4 의 일이다
  (`IMPLEMENTATION_PLAN.md` M11).
- `RecordLibraryDrawer` 는 보관함 서랍의 "음악" 탭이 된다. 하단의 백업 패널은 빠지고 안내 한 줄이 남는다.
- 실기기 확인 전에는 모바일 시트 배치(결정 4)를 확정이라 부르지 않는다.

## 보완 (M11-2, 2026-11-12) — 구현과 실측으로 바뀐 것

- **결정 4 (모바일 배치)를 실측으로 다듬었다.** 배치가 셋이 됐다 — 나란히(넓은 화면) · 쌓기(세로, 폭 900px 이하) ·
  **옆(가로, 높이 560px 이하)**. 처음에는 가로 폰도 나란히였는데, 실제 Chromium 667×375 에서 영상 위 제목 줄 때문에
  영상 200px 중 165px 만 화면에 남았다. 옆 배치는 영상을 화면 위로 올리고 보관함을 **영상의 실제 오른쪽 끝**부터 둔다.
- 쌓기 · 옆 배치는 `position: sticky` 를 쓰지 않는다 (M7 에서 되돌린 방식). 영상을 화면 위로 스크롤한 뒤 **실제 영상
  상자의 사각형**(`getBoundingClientRect`)에 보관함 경계를 맞추고, 열린 동안 페이지 스크롤을 잠근다.
- 실측 (Chrome for Testing 157, 실제 YouTube iframe, 두 테마 × 11 화면 = 22회): iframe 높이 최소 **200px**(320 · 360 ·
  375 · 390 폭 모두 정확히 200), 가림 판정점 5곳이 모두 iframe, 가로 넘침 0, 열기 · 보관함 스크롤 · 탭 전환 · 닫기 동안
  재생 유지 · iframe 노드 동일. 상세는 `IMPLEMENTATION_PLAN.md` M11-2.
- **결정 5 (Moments 위젯 축소)** 는 M11-3, **결정 8 (대량 표시)** 은 M11-4 에서 한다. M11-2 의 보관함 Moments 탭은
  M9 의 관리 기능(거르기 · 재생 · 메모 수정 · 삭제)을 그대로 잇는다.
- 보관함의 Moments 탭은 처음 열 때 마운트한다 — 열어 보지 않은 목록을 미리 그리지 않는다.
- 실기기(iOS Safari 의 스크롤 잠금 · 동적 도구 막대, Android 회전)는 확인하지 못했다.
