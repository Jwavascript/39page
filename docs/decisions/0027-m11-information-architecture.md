# 0027. M11 정보 구조 — 대시보드는 그대로 두고, 라이브러리와 Moments 를 한 "보관함" 의 두 탭으로, 데이터는 헤더의 대화상자로

- 상태: **제안 — M11-1 (2026-11-12).** 사용자 승인 뒤 M11-2 에서 구현한다. 선택지는 `M11_UX_DESIGN.md` §10 D1–D8
- 관련: **ADR 0002** (플레이어 영속), **ADR 0011** (가시성 가드), **ADR 0016** (플레이리스트 표면), **ADR 0018**
  (백업), **ADR 0019 · 0021** (Moments), `docs/product/M11_UX_DESIGN.md`, 시안 `design/mockups/m11-1/index.html`

## 배경

실사용 · 외부 테스트(Claude for Chrome)에서 첫 방문자가 백업을 찾지 못했고(플레이리스트 편집 드로어 맨 아래에만
있다), 데스크톱 Moments 목록은 1~2행만 보이며, 라이브러리와 Moments 가 서로를 모른다. 헤더에는 이름 있는 입구가
없다. 자세한 목록 · 근거 등급은 `M11_UX_DESIGN.md` §1.

## 결정 (제안)

1. **역할 넷, 표면 셋.** Dashboard(그대로) · **보관함 서랍** (탭 "음악" · "Moments") · **데이터 대화상자**.
2. **헤더에 이름 있는 입구 셋** — "♪ 음악" · "◆ Moments" · "⇩ 데이터". 모든 폭에서 글자 이름을 남긴다. 대시보드
   안의 입구(타일 · "모두 보기")도 같은 서랍 · 같은 탭으로 간다.
3. **보관함이 열린 동안 데스크톱 그리드를 CSS 로만 바꾼다** — 데크 · 셸프 · 마스코트 · 정보 열을 감추고(지우지
   않는다) 플레이어(≥360px)와 보관함만 둔다. 플레이어 노드는 움직이지 않는다 (ADR 0002 금지 목록 준수).
4. **모바일은 1열 대시보드**, 보관함은 **플레이어를 위에 남긴 채** 그 아래를 채우는 시트 — 16:9 플레이어가 360px
   폭에서 202px 로 가시성 하한(200px)을 지킨다 [실기기 확인 필요].
5. **대시보드의 Moments 위젯은 "이 곡의 Moments" 미리보기**(최대 3행 + 빠른 저장 + 모두 보기)로 줄이고, 수정 · 삭제 ·
   검색은 보관함에서만 한다.
6. **데이터는 독립, 탐색은 통합** — Moment 저장 형식 · 키를 바꾸지 않는다. 곡 ↔ Moments 연결은 표시 계층에서
   `videoId` 로 잇는다.
7. **백업은 `BackupPanel` 을 데이터 대화상자로 옮겨 붙인다** — 내보내기 · 가져오기 · 보호 로직은 바꾸지 않는다.
8. **Moments 대량 표시는 묶음 접기 + 30묶음씩 점진 표시**, 페이지 번호 없음, 가상 스크롤은 5,000개 실측 뒤.

## 대안

| 안                                            | 기각 이유                                                                                                               |
| --------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| A. 기능별 서랍 (Moments · 데이터 서랍을 더함) | 340px 폭에 검색 · 묶음이 비좁고 서랍 셋의 열림 규칙이 얽힌다. 변경이 가장 작다는 장점은 C 가 껍데기를 재사용해 가져간다 |
| B. 별도 관리 화면 (`#library` · `#moments`)   | 관리 화면에서 플레이어가 보이지 않아 가시성 가드(ADR 0011)가 재생을 멈춘다. 미니 플레이어 · 화면 전환이 큰 변경         |
| 아이콘만 있는 헤더                            | U4 (버튼이 많고 이름이 없다) 를 되풀이한다                                                                              |
| 대시보드에서 바로 편집 유지                   | 106px 목록 · 겹친 스크롤(U6 · U7) 의 원인                                                                               |

  (`IMPLEMENTATION_PLAN.md` M11).
