# 0002. 플레이어 iframe은 부모를 고정하고 Vue 재조정 대상에서 제외한다

- 상태: 채택
- 날짜: 2026-11-02
- 관련: `docs/architecture/SYSTEM_DESIGN.md` §4

## 배경

`AGENTS.md` 규칙 5는 테마 전환이 재생 상태를 초기화하지 않을 것을 요구한다.
단순히 "언마운트하지 않기"로는 부족하다. YouTube 플레이어는 iframe이고,
iframe에는 세 가지 성질이 있다.

1. 언마운트하면 재생 상태가 사라진다.
2. **DOM에서 부모를 바꾸면(re-parenting) 문서가 재로드된다.**
   노드를 옮기는 것은 언마운트와 동등하게 파괴적이다.
3. `YT.Player(id, …)`는 지정한 엘리먼트를 **iframe으로 교체한다.**
   Vue 렌더러가 같은 엘리먼트를 관리하면 충돌한다.

## 결정

세 가지를 함께 적용한다.

1. **플레이어 호스트는 테마에 무관한 안정 컴포넌트(`PlayerSurface`)가 소유한다.**
   테마별 서브트리 밖에 두고, 앱 생애주기 동안 한 번만 마운트한다.
2. **API가 교체할 노드는 Vue 템플릿에 두지 않는다.**
   Vue가 관리하는 안정 래퍼 안에, 어댑터가 명령형으로 자식 노드를 만든다.
   Vue는 그 노드를 패치하지 않는다.
3. **시각적 배치는 CSS로만 바꾼다.** `grid-area`, `transform`, `position`, 크기.
   CSS 배치는 re-parenting이 아니므로 안전하다.

금지 패턴을 명시한다: `<Teleport>`로 플레이어 이동, 테마별 컴포넌트 내부 배치,
`v-if` 표시 전환, `<KeepAlive>` 의존, `:key`에 테마·스킨 포함,
DOM 노드를 재배치하는 드래그 라이브러리.

## 대안

| 대안                                         | 탈락 이유                                                                                |
| -------------------------------------------- | ---------------------------------------------------------------------------------------- |
| `<Teleport>`로 슬롯 이동                     | 노드를 re-parenting한다 → iframe 재로드                                                  |
| `<KeepAlive>` 캐싱                           | DOM에서 분리되므로 iframe 재로드                                                         |
| 절대 위치 오버레이 레이어 + 슬롯 사각형 측정 | 더 복잡하고 가시성 가드와 상호작용이 늘어난다. CSS 그리드 배치로 해결되지 않을 때만 검토 |

## 결과

- 테마 전환과 위젯 이동·크기 변경이 플레이어와 양립한다.
  CSS Grid는 DOM 순서와 무관하게 배치하므로 re-parenting이 발생하지 않는다.
- **향후 드래그 앤 드롭 라이브러리 선택이 제약된다.** DOM 노드를 재배치하는
  라이브러리는 쓸 수 없다. 좌표만 계산하고 배치는 CSS에 맡겨야 한다.
  도입 시 `AGENTS.md` 규칙 8에 따라 ADR을 추가한다.
- `PlayerAdapter` 인터페이스로 추상화해 테스트에서 `FakePlayerAdapter`를 주입한다.
- 통합 테스트로 검증한다: 전환 후 상태 동일 / 호스트 노드 동일 인스턴스 /
  `mount` 재호출 없음.
