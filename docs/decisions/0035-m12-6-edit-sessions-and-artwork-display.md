# 0035. 편집 세션을 진입 의도에 맞추고 Artwork 구도는 원본과 분리해 연결에 저장한다

- 상태: 채택 · M12-6 사용자 지시 (2026-11-15), 로컬 브랜치 `m12-6-ux-polish`
- 관련: ADR 0029 · 0030 · 0033 · 0034. 화면 재배치·서버·배포는 범위 밖이다.

## 결정

1. 보관함의 상위 상태(선택 목록, 마지막 탭)는 유지하고, 닫기·외부 진입은 음악 하위 편집 세션을 초기화한다.
   헤더는 마지막 탭, 데크는 음악 목록, NOW PLAYLIST 편집은 해당 목록 상세, 카드 그림은 해당 트랙 설정이다.
   명시적 Moments 모두 보기는 검색을 지우고 전체 필터를 연다. 곡 배지는 videoId 필터를 연다.
2. 미저장 파일·입력·구도 변경은 보관함 안 확인에서 계속 편집/버리고 나가기를 고른다. 단순 라디오 변경은
   취소로 버린다. 저장 중에는 닫지 않는다. 업로드는 검증된 Blob과 Object URL만 메모리에 들고 있으며,
   IndexedDB 임시 자산을 만들지 않는다. 닫을 때 URL과 늦은 검증 응답을 정리한다. Moment 공유 초안은 ADR 0030대로 유지한다.
3. Moment 곡 변경 경고는 입력과 동작 단추 뒤에 둔다. 캡처된 videoId·시점·실패 시 메모 유지 정책은 그대로다.
4. 링크 추가 제출은 400ms debounce를 건너뛰고 같은 oEmbed 조회를 최대 4초까지 기다린다. 실패하면 영상 ID 제목으로
   추가한다. 수동 입력은 덮지 않고, 양식 세션·영상이 바뀐 응답은 버린다. 저장된 제목은 수정하지 않는다.
   JSON 파싱 오류는 응답 형식 실패로 구분한다. IFrame 보조 제목은 도입하지 않는다: 기존 어댑터에 실제 제목 정보가 없고,
   [공식 IFrame API 명세](https://developers.google.com/youtube/iframe_api_reference)에 제목 반환 함수는 문서화되어 있지 않다.
   큐의 사용자 제목을 실제 YouTube 제목으로 추측하지 않는다.
5. 카세트 레이블은 코디네이터 큐의 출처 이름, 큐가 없으면 선택 목록, 출처 불명이면 `KAWAII SYNTH MIX`다.
   카세트의 기존 레이블 상자 안 `foreignObject`에 한 줄 말줄임을 적용하고 전체 제목은 tooltip·SVG 접근성 이름에 둔다.
   Mono Vinyl·참고 HTML·큐의 영속 형식은 변경하지 않는다.
6. `ArtworkAssignment.display?: { fit, positionX, positionY, zoom }`를 더한다. 기본은 cover·50·50·1,
   위치 범위는 0–100%, zoom은 1–3배다. 생략은 이전 데이터의 기본값이고 잘못된 값·NaN·무한·부분 객체는 거절한다.
   사용자 이미지에 `object-fit`, `object-position`, `scale`, 같은 위치의 `transform-origin`을 적용한다.
   위치 p에서 이미지 시작점은 `(카드 크기 − 확대된 이미지 크기) × p / 100`이다. cover는 틈을 만들지 않고,
   contain의 여백은 종횡비를 보존하기 위해 의도적으로 남는다. 원본 픽셀·GIF·SHA-256·assetId는 바꾸지 않는다.
7. IndexedDB는 **v1 유지**: 키·색인·object store를 바꾸지 않는 선택 필드라 재작성·일괄 마이그레이션이 필요 없다.
   구도만 바꿀 때 기존 assetId를 참조하고 assignments만 쓴다. 기존 트랜잭션·revision 충돌 검사·실패 rollback·탭 알림을 쓴다.
8. 전체 ZIP manifest와 artwork.json, 공유 manifest와 share.json은 **v2**로 내보낸다. v1/v2는 읽고 미래 버전은 거절한다.
   v1에서 display 생략은 기본값이다. v2로 올린 이유는 구버전 앱이 구도를 무시하고 복원 성공으로 표시하는 것을 막기 위해서다.
   내부 `backup.json`의 기존 JSON 형식은 그대로다. staging·텍스트 확정·연결 확정·재시도·누락 자산 fallback은 유지한다.
9. 관리 메뉴의 목록·곡 공유는 `SHARE_DIALOG` 공용 계약으로 기존 데이터 대화상자와 SharePanel을 연다.
   playlistId·trackId를 명시적으로 넘기고 선택된 라이브러리 목록을 바꾸지 않는다. 문맥 진입마다 Moments는 꺼진 상태로 시작한다.

## 대안과 한계

- 이미지 재인코딩: GIF 애니메이션·해시·원본을 바꾸므로 채택하지 않는다.
- 자산별 구도: 같은 이미지의 곡별 구도가 독립적이지 않아 채택하지 않는다.
- v1 ZIP에 선택 필드만 추가: 구버전 앱의 조용한 구도 누락 때문에 채택하지 않는다.
- 새 라이브러리: 필요 없다. Vue·네이티브 포인터 이벤트·기존 IndexedDB/ZIP 모듈을 사용한다.
