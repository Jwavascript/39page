# 0044. 설명 글을 줄이고, 행의 "관리" 메뉴 대신 아이콘, Moments 탭은 음악 탭처럼 두 칸

- 상태: 채택 — 사용자 요청 (2026-11-21, ADR 0043 배포 뒤 실제 사용), 브랜치 `feat/quiet-ui`
- 관련: ADR 0030 (M11-7 — 대시보드 · 보관함 역할, 트랙 편집 C, Moments 보기 순서 · "이 곡" 관리 화면 — 이 결정이 행 동작과
  Moments 탭 배치를 고친다) · ADR 0027 (보관함 정보 구조) · ADR 0043 (공유 대화상자) · ADR 0001 (테마 — 데크 아트)

## 배경

ADR 0043 을 배포한 뒤 사용자가 써 보고 짚었다 (2026-11-21).

- 굳이 필요 없는 문구가 많다. "누르면 지금 시점을 잡아요(음악은 계속 흘러요) …" 처럼 설명이 많이 달려 AI 가 디자인한 것처럼 보인다.
- 카세트의 "SYNTH / CASSETTE" 는 없어도 된다.
- NOW PLAYLIST 의 "보관함에서 편집" 은 카세트를 누르는 것과 같으니 빼도 된다.
- 모든 단추에 글자가 있다. 글자가 있어야 알 수 있는 단추도 있지만, 보관함 닫기처럼 × 만 있어도 아는 단추도 있다.
- 보관함 Moments 는 순간이 많아도 보이는 칸이 낮아 불편하다. 음악 탭처럼 왼쪽 · 오른쪽으로 나누면 높이를 얻는다.
- 음악 · Moments 모두 "관리" 를 눌러야 메모 수정 · 공유 · 삭제를 할 수 있다. 행 오른쪽에 아이콘(수정은 연필, 공유는 공유,
  삭제는 휴지통)만 두어 바로 하게 한다.

## 결정

1. **늘 보이는 설명 글을 뺀다.** 상태 · 오류 · 확인 문구(저장하지 못했어요, 지울까요 등)는 그대로 둔다.

   | 자리                    | 뺀 글                                                                                 |
   | ----------------------- | ------------------------------------------------------------------------------------- |
   | 데크 아래               | "✧ 카세트를 누르면 믹스테이프 보관함이 열려요" · "◉ LP를 누르면 …" (테마 문구도 지움) |
   | 영상 자리               | "영상은 이 위치에 16:9로 … 곡을 선택하세요" — "YOUTUBE / VIDEO" 만                    |
   | 재생 카드 (곡 없음)     | "카세트 · LP 나 ▤ 보관함에서 …" · "재생 목록을 만들고 …" — 제목만                     |
   | 재생 카드 아래          | "YouTube 공식 영상·컨트롤은 그대로 표시됩니다."                                       |
   | NOW PLAYLIST            | "· 곡을 누르면 그 곡부터 재생" · 목록 바꾸기의 안내 줄 · 빈 목록의 두 줄 안내         |
   | Moment 저장 단추 옆     | 쓰는 법 · "곡을 재생하면 …" · "재생이 시작되면 …" — 막힌 이유(플레이어 없음 · 오류)만 |
   | 대시보드 Moments (곡 X) | "곡을 재생하면 지금 이 순간을 저장하고 …"                                             |
   | 보관함 바닥             | "Esc 또는 × 로 닫아요 …" · "다른 기기로 옮길 때는 …"                                  |
   | 음악 탭                 | "/ YOUTUBE ONLY" · "TRACKS" · "보관함 › 음악 › 이 목록" · 순서 편집 도움말 · 빈 안내  |
   | 목록 칸                 | 새 목록 양식의 안내 · "＋ 새 목록으로 시작하세요" · "재생 중인 목록" → "재생 중"      |
   | YouTube 검색            | "검색 결과는 새 탭에서 열려요 …"                                                      |
   | Moments 탭              | "이 곡 · Moments N개" 머리 · "‘…’ 의 순간만 보는 중" · 긴 빈 안내 · 검색 안내 뒷말    |

2. **카세트 아트의 머리 글을 뺀다** — "SYNTH / CASSETTE" 와 그 아래 "MLF • DIGITAL MIX TAPE / 02". 다른 좌표 · 색은 그대로다.
   `design/references/` 는 고치지 않았다 (시험은 이 차이를 의도한 변경으로 적는다).
3. **"보관함에서 편집" 을 없애고 데크가 그 일을 한다** — 데크(카세트 · LP)를 누르면 좁은 보관함에서도 목록 단계를 건너뛰고
   고른 목록의 곡으로 연다(`showDetail`). 목록은 ‹ 로 돌아가 고른다.
4. **행의 "관리" 메뉴 대신 오른쪽 아이콘** — 글자 없이, 이름은 `aria-label` · `title`(툴팁).

   | 행     | 아이콘                                                     |
   | ------ | ---------------------------------------------------------- |
   | 곡     | 연필(이름 바꾸기) · 그림(앨범아트) · 공유 · 휴지통(삭제)   |
   | 목록   | 연필(이름 수정) · 공유 · 휴지통(삭제 — 마지막 목록은 꺼짐) |
   | Moment | 연필(메모 수정) · 공유 · 휴지통(삭제)                      |
   - 되돌리기 어려운 삭제는 맨 끝이고, 확인은 그대로 **그 행 바로 아래**에서 받는다. 연필 · 휴지통은 양식 · 확인을 여닫는
     토글이고(`aria-expanded`), 닫히면 포커스가 그 아이콘으로 돌아온다.
   - 곡의 맨 위로 · 맨 아래로는 메뉴와 함께 없어졌다 — 손잡이(⠿)의 Home · End 로 한다. 한 칸 위 · 아래는 **순서 모드**(⇅,
     이전의 "✎ 편집 / 완료")에서 ↑ · ↓ 아이콘으로 한다. 순서 모드에서는 행 아이콘이 잠시 숨는다.
   - 좁은 목록(520px 이하)에서는 곡 행의 아이콘이 제목 아래 줄 오른쪽으로 내려간다 — 제목이 아이콘에 밀려 눌리지 않게.

5. **아이콘만 있는 단추** — 보관함 닫기(띠 배치의 "보관함 닫기 ×" → ×), 음악 상세의 "‹ 목록으로" → ‹, 순서 모드 ⇅, 위 · 아래
   ↑ · ↓. 글자가 있어야 뜻이 서는 단추(목록 전체 재생 · YouTube 링크 추가 · ＋ 새 목록 · ＋ 이 순간 저장 · 목록 바꾸기 · 모두 보기 ·
   헤더의 보관함 · 데이터 · 백업)는 그대로 둔다.
6. **아이콘은 CSS 마스크 하나** — `<span class="ui-icon ui-icon--edit">`, 그림은 `base.css` 의 SVG 데이터 URL, 색은 글자색
   (`currentColor`), 18px. 단추는 `.icon-button` 40×40 (WCAG 2.5.8 의 24px 를 넉넉히 넘는다). 처음에는 SVG 컴포넌트로 만들었는데
   곡 400개 목록에서 그리기가 약 4배 느려져(jsdom 1.4초 → 5.8초) 노드 하나로 바꿨다(1.9초).
7. **Moments 탭은 두 칸** — 음악 탭과 같은 비율 · 여백이고, 두 칸이 각자 스크롤한다(보관함 본문은 스크롤하지 않는다).
   - 왼쪽: 개수, 검색, 보기(이 곡 — 곡이 재생 중이거나 초안이 있을 때만 · 전체 · 최근), 순간이 있는 **곡 목록**(이름 · 개수 · 재생 중
     ♪, 100곡씩). 고른 것은 `aria-current`.
   - 오른쪽: 고른 것의 머리(곡 이름 또는 보기 이름 · 개수 · 그 곡이 든 목록) 아래 순간 목록. 이 곡 보기에서는 머리 아래에
     ＋ 이 순간 저장. **한 곡 보기도 이 곡처럼 한 목록**(묶음 머리 없음)이다. 전체 보기는 그대로 곡별 묶음이다.
   - 검색을 시작하면 이 곡 · 한 곡 보기에서 **전체**로 가고, 왼쪽 곡 목록에는 맞는 곡만 남는다(맞는 수 / 전체 수). 곡을 고르면
     검색어를 둔 채 그 곡의 맞는 순간만 본다.
   - 보관함이 640px 이하면 한 번에 한 칸 — 오른쪽 칸의 ‹ 로 왼쪽, 왼쪽에서 고르면 오른쪽.

## 대안

- **설명 글을 툴팁 · 도움말 단추로 옮기기** — 글은 줄지만 "?" 단추가 하나 더 생긴다. 막힌 이유 · 확인은 그 자리에 남겼다.
- **행에 "⋯" 하나를 두고 메뉴** — 누름이 한 번 더 든다. 사용자는 바로 누르는 아이콘을 원했다.
- **아이콘을 마우스를 올릴 때만 보이기** — 터치 화면에서는 보이지 않는다. 늘 보인다.
- **Moments 를 지금처럼 한 칸에 두고 머리 · 칩을 접기** — 칩을 접어도 곡을 찾으려면 묶음을 펼쳐 내려가야 한다. 곡 목록을 왼쪽
  칸으로 빼면 곡 선택과 순간 보기가 동시에 된다.
- **바닥(footer)의 테마 표기도 빼기** — 이번 요청의 예시(설명 글 · 카세트 머리 글)와 성격이 같아 보이지만 확정 디자인의 일부라
  남겼다. TODO 로 사용자에게 묻는다.

## 결과

- 새 의존성 · 새 저장 키 · 데이터 형식 변경 없음. 확장 계약 그대로.
- 지운 것: `NowPlaylistWidget` 의 "보관함에서 편집"과 `useNowPlaylist.openInArchive`, 테마 메타의 `deck.hintMark` · `hintStrong` ·
  `hintRest`, `TrackList` 의 관리 메뉴(`track-controls` · 맨 위로 · 맨 아래로), `ArchivePlaylistNav` 의 관리 메뉴(`list-manage`),
  `MomentRow` 의 관리 메뉴(`moment-manage` · `'manage'` 모드), Moments 탭의 칩 · 붙는 도구 줄 · 스크롤 여백 처리.
- 더한 것: `useMomentsArchive` 의 `songs` · `songHead` · `focusVideo(…, { keepQuery })`, `base.css` 의 `.ui-icon` · `.icon-button` ·
  `.row-icons`, `TrackList` 의 `canShare`.
- 시험: 관리 메뉴 · 칩 · 설명 글을 보던 시험을 새 아이콘 · 두 칸 · 빈 글로 바꿨다. 지운 시험은 없다(옛 동작을 보던 것은 그 자리에서
  새 동작을 본다). 시험 도우미 `openTrackManage` 는 행 아이콘이 있는지만 보고, `setReorderMode` 를 더했다.
