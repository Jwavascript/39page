# 0032. 마스코트 패널을 Now Playing 카드로 바꾸고, 곡 정보 · 재생 조작을 영상 아래 카드 한 곳에 둔다

- 상태: **채택 — M12-1 설계 (2026-11-15, 사용자 지시)** · 구현 M12-2
- 관련: ADR 0001 (테마 전환) · 0002 (플레이어 영속) · 0003 (위젯 레지스트리) · 0005 (Grid 영역) · 0010 (상태 안내) ·
  0011 (가시성 가드) · 0030 (대시보드 · 보관함 역할), `docs/product/M12_CUSTOM_ARTWORK.md`

## 배경

M1 부터 데크 아래(M7 부터 영상 아래)에 도트 마스코트 패널(`COMPANION / 01`)이 있었고, 곡 제목 · 부제 · 재생 조작은
`PlayerSurface` 안 영상 **위아래**에 있었다. 사용자가 M12 를 곡별 Custom Artwork 로 다시 정의했고, 지금 곡의 그림 · 제목 ·
조작을 영상 바로 아래 한 카드에 모으는 배치를 골랐다 (세로 · 가로 시안, M12 지시서 Part B).

## 결정

1. 마스코트 위젯(`mascot`)을 **뺀다.** 그 자리를 지금 곡의 **Now Playing 카드**(`src/features/playback/NowPlayingCard.vue` —
   앨범아트 · 제목 · 부제(큐 위치 · 상태 · 지금 초) · `PlayerTransport` · 상태 안내 · 공식 컨트롤 안내)가 쓴다. 그림 표시는
   `src/features/artwork/ArtworkImage.vue` 를 쓴다 (보관함이 라이브러리 · Moments 화면을 쓰듯 조립 지점이 다른 기능의 공개 컴포넌트를
   쓴다. M12-3 부터 데이터 경계는 `stores/artwork`).
2. **카드는 플레이어 위젯(`PlayerSurface`) 안, 영상 상자의 바로 다음 형제다** — 어댑터 소유 영역 밖이고, M11 까지 제목 · 조작이 있던
   것과 같은 층이다. 영상 위아래의 제목 · 부제 · 조작 · 상태 줄은 카드로 **옮겼다** — 사본을 두지 않는다. 어댑터 소유 영역 · 가시성
   감시 · 마운트 순서는 바뀌지 않는다 (ADR 0002 · 0011).
   - 처음에는 카드를 따로 된 위젯(`nowplaying` 그리드 영역)으로 두었다. 실제 Chrome 실측에서 세 열이 한 행 높이를 나눠 쓰는 탓에 영상과
     카드 사이가 81 ~ 165px 벌어지고 NOW PLAYLIST 가 270px 밀렸다 (1440 · 844×390 · 200%). 행 정의로는 세 열의 흐름을 따로 맞출 수 없어
     위젯 안으로 옮겼다 — 이제 모든 배치에서 영상과 카드 사이가 14px(보관함 쌓기 6px)다.
3. 레이아웃 상수에서 `mascot-main` 을 지운다. 위젯은 6개(데크 · 시계 · 날씨 · 플레이어 · NOW PLAYLIST · Moments)이고 플레이어 인스턴스
   `player-main` 의 키 · 순서는 그대로다. 넓은 화면은 `deck player clock` / `deck player weather` / `playlist player moments` 3 행 —
   Moments 는 시계 · 날씨 아래 남는 높이를 쓴다. 레이아웃은 저장하지 않으므로 마이그레이션이 없다.
4. 보관함이 열리면 같은 카드가 재생 띠에 선다 — 띠(strip)는 플레이어 안에서 [영상 | 카드(그림 72px)], 쌓기 · 옆은 영상 → 한 줄 카드
   (그림 없음 · 제목 · 조작). CSS 로만 다시 놓는다.
5. 마스코트 코드(`features/mascot/*`) · 테마 메타데이터의 `mascot` 문구 · `--mascot-*` 토큰을 지운다. 기본 Artwork 의 카세트 도트
   그림은 도트 렌더러를 `features/artwork/` 로 옮겨 다시 쓴다.
6. 승인된 디자인 레퍼런스(`design/references/`)는 고치지 않는다. 레퍼런스의 마스코트 패널 · 영상 위 제목과 다른 것은 사용자의
   M12 지시에 따른 의도된 차이다 (M6-1 의 3열 전환과 같은 성격).

## 결과

- 장점: 같은 곡 정보 · 버튼이 한 화면에 한 번만 있다. 영상 위 공간이 줄어 넓은 화면에서 영상이 더 위로 온다. 마스코트 대신
  곡마다 다른 얼굴이 생긴다.
- 대가: 영상 위 제목을 전제한 시험 · 실제 Chrome 스크립트 · 문서를 고친다. 레퍼런스와의 차이가 하나 더 생긴다.
- 확인 (M12-2): iframe 노드 동일 · 영상 202px 이상 · 카드가 영상을 덮지 않음 · 영상 위에 제목 · 조작 없음 — 시험
  `now-playing-card.spec.ts` 17개, 실제 Chrome 36/36 (두 테마 × 1440 · 1280 · 1024 · 768 · 844×390 · 390 · 360 · 320 · 200% 확대,
  각각 보관함 닫힘 · 열림, `docs/development/m12-results/real-chrome-layout.json`).
