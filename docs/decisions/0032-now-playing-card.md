# 0032. 마스코트 패널을 Now Playing 카드로 바꾸고, 곡 정보 · 재생 조작을 영상 아래 카드 한 곳에 둔다

- 상태: **채택 — M12-1 설계 (2026-11-15, 사용자 지시)** · 구현 M12-2
- 관련: ADR 0001 (테마 전환) · 0002 (플레이어 영속) · 0003 (위젯 레지스트리) · 0005 (Grid 영역) · 0010 (상태 안내) ·
  0011 (가시성 가드) · 0030 (대시보드 · 보관함 역할), `docs/product/M12_CUSTOM_ARTWORK.md`

## 배경

M1 부터 데크 아래(M7 부터 영상 아래)에 도트 마스코트 패널(`COMPANION / 01`)이 있었고, 곡 제목 · 부제 · 재생 조작은
`PlayerSurface` 안 영상 **위아래**에 있었다. 사용자가 M12 를 곡별 Custom Artwork 로 다시 정의했고, 지금 곡의 그림 · 제목 ·
조작을 영상 바로 아래 한 카드에 모으는 배치를 골랐다 (세로 · 가로 시안, M12 지시서 Part B).

## 결정

1. 위젯 종류 `mascot` 을 **`nowplaying`** 으로 바꾼다 (영역 이름도). 컴포넌트는 `src/features/playback/NowPlayingCard.vue` —
   제목 · 부제 · 재생 위치 · `PlayerTransport` · 상태 안내 · 그림. 그림 표시는 `src/features/artwork/ArtworkImage.vue` 를 쓴다
   (보관함이 라이브러리 · Moments 화면을 쓰듯 조립 지점이 다른 기능의 공개 컴포넌트를 쓴다. 데이터 경계는 `stores/artwork`).
2. `PlayerSurface` 는 **영상 상자만** 남는다(+ 영상 전 안내). 제목 · 부제 · 조작 · 상태 줄을 카드로 **옮긴다** — 사본을 두지 않는다.
   어댑터 소유 영역 · 가시성 감시 · 마운트 순서는 바뀌지 않는다 (ADR 0002 · 0011).
3. 레이아웃 상수에서 인스턴스 `mascot-main` 을 `nowplaying-main` 으로 바꾼다. 플레이어 인스턴스 `player-main` 의 키 · 순서는 그대로다.
   레이아웃은 저장하지 않으므로 마이그레이션이 없다.
4. 보관함이 열리면 같은 카드 인스턴스가 재생 띠에 선다 (`player nowplaying moments`). CSS 로만 다시 놓는다.
5. 마스코트 코드(`features/mascot/*`) · 테마 메타데이터의 `mascot` 문구 · `--mascot-*` 토큰을 지운다. 기본 Artwork 의 카세트 도트
   그림은 도트 렌더러를 `features/artwork/` 로 옮겨 다시 쓴다.
6. 승인된 디자인 레퍼런스(`design/references/`)는 고치지 않는다. 레퍼런스의 마스코트 패널 · 영상 위 제목과 다른 것은 사용자의
   M12 지시에 따른 의도된 차이다 (M6-1 의 3열 전환과 같은 성격).

## 결과

- 장점: 같은 곡 정보 · 버튼이 한 화면에 한 번만 있다. 영상 위 공간이 줄어 넓은 화면에서 영상이 더 위로 온다. 마스코트 대신
  곡마다 다른 얼굴이 생긴다.
- 대가: 영상 위 제목을 전제한 시험 · 실제 Chrome 스크립트 · 문서를 고친다. 레퍼런스와의 차이가 하나 더 생긴다.
- 확인: iframe 노드 동일(테마 · 보관함 · 크기 · 그림 변경), 영상 202px 이상, 카드가 영상을 덮지 않음 — M12-2 시험 · 실측.
