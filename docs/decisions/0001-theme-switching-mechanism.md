# 0001. 테마 전환은 루트 속성 교체로 한다

- 상태: 채택
- 날짜: 2026-11-02
- 관련: `docs/architecture/THEME_SYSTEM.md` §3

## 배경

M0에서 테마 적용 방식을 세 후보로 남겨두었다.

- A: 루트 엘리먼트의 `data-theme` 속성 교체
- B: 테마별 클래스 토글
- C: 테마별 스타일시트 동적 로드

`AGENTS.md` 규칙 5는 테마 전환이 재생 상태를 초기화하지 않을 것을 요구한다.
YouTube 플레이어는 iframe이므로 언마운트되거나 DOM에서 옮겨지면 재생이 끊긴다.

## 결정

**A를 채택한다.** 루트에 `data-theme` 속성을 두고 값을 교체한다.

데크 아트(턴테이블 / 카세트)는 색 토큰으로 표현할 수 없는 서로 다른 SVG이므로,
두 아트를 동시에 DOM에 두고 CSS `display`로만 전환한다.

승인된 디자인 `two-themes-v09.html`이 이미 이 방식을 쓴다
(`document.body.classList.toggle('theme-kawaii', isSynth)`).
제품에서는 테마가 2개를 넘길 가능성을 고려해 클래스 대신 속성을 쓴다.

## 대안

| 후보                      | 탈락 이유                                               |
| ------------------------- | ------------------------------------------------------- |
| B (클래스 토글)           | 기능상 A와 동등. 테마가 늘어날 때 속성 값이 더 명확하다 |
| C (스타일시트 동적 로드)  | 전환 지연과 FOUC 위험. 승인된 디자인은 즉시 전환한다    |
| 테마별 컴포넌트 트리 교체 | 서브트리 언마운트 → 플레이어 파괴. 규칙 5 위반          |

## 결과

- 전환이 속성 변경 한 번이므로 컴포넌트 트리가 바뀌지 않는다.
  규칙 5가 **구조적으로** 보장된다.
- 컴포넌트는 의미 토큰만 참조해야 한다. 테마별 색 하드코딩을 금지한다.
- 두 데크 SVG가 항상 번들에 포함된다. 번들 크기 영향은 측정 대상이다.
- 두 SVG가 동시에 DOM에 있으므로 `<defs>` id 충돌을 막는 접두사 규칙이 필요하다.
