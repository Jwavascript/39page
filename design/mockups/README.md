# design/mockups — 비교 시안 (구현 아님)

설계 단계에서 대안을 비교하려고 만든 **정적 시안**을 둔다.

- **승인된 디자인 레퍼런스가 아니다.** 확정 레퍼런스는 `design/references/` 뿐이고(읽기 전용, `AGENTS.md` 규칙 6),
  이 폴더는 그것을 대신하지 않는다.
- **실제 구현이 아니다.** 빌드 대상이 아니며 앱이 가져오지 않는다. 시안마다 "구현 아님" 띠를 단다.
- 토큰 값은 `src/themes/*/tokens.css` 에서 옮겨 적었다 — 토큰이 바뀌어도 시안은 따라가지 않는다.
